01

Build the list

Fixed text stays unchanged. Use blocks in braces for unknown parts.

Build a pattern

{digits:4} → 0000 to 9999

{lower:2-3} → 2 to 3 lowercase letters

{upper:2} · {hex:4} · {alnum:3}

{range:1:31:2} → 01 to 31

{words:public,interne,final} → custom words

{chars:abc123:2} → your alphabet, 2 characters

Multiple blocks can be combined: rapport-{range:2024:2026}-{range:1:12:2}.pdf.

Asterisks are literal text, not placeholders. Combining blocks can produce duplicates when their boundaries are ambiguous.
