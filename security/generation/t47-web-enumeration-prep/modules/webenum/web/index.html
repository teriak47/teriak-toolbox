01

Construire la liste

Les parties fixes restent telles quelles. Remplace les inconnues par des blocs entre accolades.

Composer un motif

{digits:4} → 0000 à 9999

{lower:2-3} → 2 à 3 lettres minuscules

{upper:2} · {hex:4} · {alnum:3}

{range:1:31:2} → 01 à 31

{words:public,interne,final} → tes propres mots

{chars:abc123:2} → ton alphabet, 2 caractères

Plusieurs blocs sont possibles : rapport-{range:2024:2026}-{range:1:12:2}.pdf.

Les étoiles seules sont du texte littéral : elles ne définissent pas les caractères à générer. Les combinaisons de plusieurs blocs peuvent produire des doublons si leurs limites sont ambiguës.
