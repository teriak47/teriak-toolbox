# Teriak Toolbox

🌐 **Language:** English | [Français](README.fr.md)

Teriak Toolbox is Teriak47's personal collection of small, reusable tools. It is designed to bring together utilities for data, systems, networks, security, development, automation, and media.

## Tool catalogue

| Tool | Purpose |
| --- | --- |
| [Event Inspector](data/inspection/t47-event-inspector/README.md) | Explore, filter, and compare JSON and NDJSON events locally. |
| [7-Point Media Rater](media/rating/t47-media-rater/README.md) | Rate media with weighted criteria and export a Markdown note. |
| [Zircolite SQL Generator](security/forensics/t47-zircolite-sql-generator/README.md) | Prepare SQL queries for the Zircolite Viewer. |
