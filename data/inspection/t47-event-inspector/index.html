Local operation, security and known limits

Privacy and offline operation: this tool runs entirely in your browser memory. A strict security policy (Content-Security-Policy: default-src 'none') blocks network communication. Files are read in 2 MB chunks without modifying the originals.

Numeric precision: large integers and high-precision decimals are handled without standard floating-point rounding where supported. Verify important values against the source file.

Timestamps: ISO timestamps retain their original text. Time sorting and filtering use BigInt; timestamps without a timezone are identified as such.

Known browser limitations: all data is kept in browser memory. Maximum file size depends on available memory and event size; close unused dataset tabs with × to free memory.
