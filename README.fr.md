# Teriak Toolbox

🌐 **Langue :** [English](README.md) | Français

Teriak Toolbox est la collection personnelle de petits outils réutilisables de Teriak47. Elle a pour but de réunir des utilitaires pour les données, les systèmes, les réseaux, la sécurité, le développement, l'automatisation et les médias.

## Catalogue des outils

| Outil | Utilité |
| --- | --- |
| [T47 Event Inspector](data/inspection/t47-event-inspector/README.md) | Explorer, filtrer et comparer localement des événements JSON et NDJSON. |
| [Graphax](data/visualization/t47-graphax-board/README.fr.md) — bêta | Créer localement des tableaux d’enquête et de recherche sous forme de graphes. |
| [T47 Media Score](media/rating/t47-media-rater/README.md) | Noter des médias avec des critères pondérés et exporter une note Markdown. |
| [T47 Zircolite SQL Generator](security/forensics/t47-zircolite-sql-generator/README.fr.md) | Préparer des requêtes SQL pour le Viewer de Zircolite. |
| [Web Enumeration Prep](security/generation/t47-web-enumeration-prep/README.fr.md) | Générer des listes de noms et préparer des commandes d’énumération web. |
