# Contributing

Teriak Toolbox is a personal collection of tools created by Teriak47. Contributions to existing tools are welcome, including bug fixes, improvements, and new features. Suggestions for new tools are encouraged, but the initial implementation of each tool is reserved for the project maintainer.

The maintainer makes the final decisions about project direction and merges. Contributions remain attributed in Git history. Issues and discussions may be written in English or French; technical documentation and pull requests are in English.

## Workflow

1. For a bug, feature, task, or proposal, open an issue when discussion or tracking is useful. An issue is not required for every pull request.
2. Create a short-lived branch from `main` for one coherent change.
3. Follow the [project conventions](docs/conventions.md), including Conventional Commits and the relevant tool's documentation.
4. Open a pull request against `main`, describe the change and its verification, and update affected documentation and metadata.
5. Review the checks and the files intended for publication. Do not include secrets, private logs, or third-party material without the necessary rights.

Pull requests are reviewed and merged using squash and merge. The maintainer deletes temporary branches after merging. Contributions are made under the project's [GPL-3.0 licence](LICENSE); check third-party compatibility and obligations before proposing dependencies or incorporated material.
